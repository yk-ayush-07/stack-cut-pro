# Stack Cut Pro - Gemini CLI Reference

Stack Cut Pro automates highlight clipping and 9:16 vertical video production from streams.

When invoked in Gemini CLI environments:
- Use `scripts/stack_cut_pro.py` for command execution.
- Pass `--brain gemini` (or `--brain auto`) during clip generation commands.
- Consult `SKILL.md` for full command line documentation.
